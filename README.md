# EK’SE — The Hustle Culture

Mobile-first streetwear brand website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system, typography and motion
- `script.js` — intro loader, scroll reveals, mobile menu, image lightbox and pointer interactions
- `images/` — supplied EK’SE photography

## Preview / deployment
This is a static site. Enable GitHub Pages for this repository from **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The public site will be available at the GitHub Pages URL shown there.

Product names, prices, social links and confirmed contact details still need to be supplied before launch.
